# Changelog

## 1.0.0

First release.

- Non-modal palette for user and model parameters, opened from a button in SOLID › MODIFY
- Sections Favorites / User Parameters / Model Parameters, with resizable columns when the palette is wide
- Edit expressions and comments; favorites shared with Fusion's own parameters dialog
- Search by name, formula, comment, value, unit, type (e.g. Distance) or the sketch/feature that created the parameter
- Add and delete user parameters
- Clear error messages for incorrect formulas
- Follows the Fusion interface theme
- Interface in English, French, German, Spanish, Italian, Portuguese, Japanese and Chinese
- Windows only
