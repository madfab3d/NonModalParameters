# Changelog

## 2.0.0

- **Formula autocomplete**: while typing a formula, suggestions list the document's parameters (with their current value), Fusion's functions and units. Up/Down to choose, Enter or Tab to insert, Esc to close, Ctrl+Space to open the list at any time. Multi-argument functions use Fusion's `;` separator, for example `max(a; b)`.
- **Rename parameters**: double-click a parameter's name, or press F2, to rename it. Invalid or already used names are rejected with a clear message.
- Error diagnostics now follow the function list of Fusion's documentation.
- Shorter "Auto" entry in the language selector.

## 1.0.0

First release.

- Non-modal palette for user and model parameters, opened from a button in SOLID › MODIFY
- Sections Favorites / User Parameters / Model Parameters, with resizable columns when the palette is wide
- Edit expressions and comments; favorites shared with Fusion's own parameters dialog
- Search by name, formula, comment, value, unit, type (e.g. Distance) or the sketch/feature that created the parameter
- Add and delete user parameters
- Clear error messages for incorrect formulas
- Follows the Fusion interface theme
- Interface in English, French, German, Spanish, Italian, Portuguese, Japanese and Chinese
- Windows only
